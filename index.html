Stretchtext

Any web page becomes stretchtext: click a phrase to grow it where it stands, click again to shrink it back.

Expansions are generated on demand by the Pollinations API and billed to the reader's own Pollen. The extension never pays for anything and holds no shared key.

Try it on this page

This install page is itself stretchtext. Click any underlined phrase below to expand it — the extension is running here as a live demo, and the expansion you get is a real Pollinations call.

Stretchtext is the idea Ted Nelson described in 1967: text that grows where the reader wants more and shrinks back where they don't. Writing every level by hand was the hard part. Here the elaboration is generated on demand, in the reader's own language and tone, and the original wording is never rewritten.

A phrase that is already short — a bare "Yes." — is left alone, because there is nothing worth expanding. Longer sentences become controls: they are focusable, and respond to Enter and Space as well as a click.

Install

Source only, no build step, no bundler. Clone or download the repository, then load it unpacked. 

git clone https://github.com/g33ky00/stretchtext.git
  1. Open chrome://extensions in Chrome, Edge, Brave or Arc.
  2. Enable Developer mode (top right).
  3. Click Load unpacked and select the stretchtext/ folder.

In Firefox, open about:debugging#/runtime/this-firefox, click Load Temporary Add-on, and select manifest.json.

Connect

Open the toolbar popup and press Connect with Pollen. The recommended path is the Pollinations device flow: approve a code on enter.pollinations.ai/device and the extension receives a scoped key that works until it expires or you revoke it. It needs no App Key — registering one only attributes the spend to your account.

Prefer to paste a key instead? Create a secret key at enter.pollinations.ai/keys and enter it on the options page. Either way the key lives in chrome.storage.session — memory-backed, cleared when the browser closes — and is sent only to gen.pollinations.ai and enter.pollinations.ai.
